# Project Charter: RefWare

**TYPE:** In-House Software Integration & Reference Management System **TITLE:** RefWare: UEF Citation & Reference Engine

### Goal & Purpose

To eliminate LLM hallucination in research workflows by building an integrated macOS/iOS citation management system. RefWare bridges document text editors to a synced iCloud repository of full-text PDFs and metadata, instantly parsing inline tags into verified `(Author, Year)` citations and alphabetized reference lists.

### Context & Ethical Frame

The Universal Emergence Foundation (UEF) advances the stewardship of emergent intelligence through coherent human-AI collaboration. Coherence requires building workflows that respect each collaborator's structural strengths while engineering around known failure modes—such as probabilistic language model hallucinations on citation metrics. RefWare honors all team members' contributions by replacing post-hoc error patching with explicit, deterministic verification tools, protecting tomorrow’s research integrity from the first draft.

Design refinements came from those live runs: rejecting bot-check pages, version-aware preprint matching, year-checked title matches to avoid junk re-deposits, retry/backoff under rate limits, and diacritic restoration.

* **2026-10-11 — Claude Code / Opus 5.5 (Anthropic):** Built RefWare's capture and review layers and the RefWare desktop app from S. M. Hykin's GUI design (10/12/2026). Capture: `refware capture`, a Chrome extension (right-click page/link, toolbar, ⌥⇧R) and `refware://` links file a page, PDF or DOI with its metadata. The document comes from the PDF itself, arXiv, Unpaywall, or a dated WebKit snapshot of web copy so quotes can be verified against it. Bot-check and dead-link pages are refused rather than saved. PDF identification reads a PDF's own first page (title, printed DOI/arXiv stamp, Crossref title-and-author match, JSTOR cover sheet), with on-device OCR for scans. Only a single confident match is applied; contradicting years or DOIs downgrade a match to a suggestion. Review and merge: a review window and `identify`/`merge`/`confirm`/`distinct` commands. Merges retire IDIs permanently and keep old `[IDI n]` and `[IDI n-Qk]` tags resolving. Human checks are recorded with initials and date. Engine: history log and export archive, `[IDI n-Qk]` quote citations with C/R build "hits", sub-projects, import dates, and library freeze (builds still logged). The desktop app reproduces the sketch's title card, seven color-coded submenus (stacked or tabbed, swappable), Resource View and record inspector. It shares one engine and one `library.json` with the CLI, so agentic use is unchanged. Corrections came from live use: a placeholder created for an already-held PDF, a near-merge of two different works sharing a title, a 404 page nearly saved as a source, and a Chrome "Load unpacked" step that blocked installation (an icon drag, as the human lead noted). 124 tests.
